# Mersey Care Talking Therapies — Skills for Wellbeing

**NHS Talking Therapies | Mersey Care | April 2025**

A 6-session course based on Cognitive Behavioural Therapy (CBT) — the recommended first-line treatment for anxiety and depression. This is a GitHub Markdown version of the course manual, enhanced for personal use.

## Course Overview

The sessions themselves won't make you feel better on their own — **using the techniques consistently** is what creates change. This booklet contains all techniques in session order, but you can use them in any order that works for you.
